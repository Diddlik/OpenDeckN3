## 🧰 Everything built in

No plugin tinkering for the basics – these actions are built in and set up in seconds:

| | Action | On a key | On a dial |
| :---: | --- | --- | --- |
| ⌨️ | **Hotkey** | Any combination – just press it, the app records it | Separate hotkey per direction |
| 🔊 | **Volume** | Up, down, or mute | Turn to adjust, press to mute |
| ⏯️ | **Media** | Play/pause, next, previous, stop | Turn to change tracks |
| 🚀 | **Open program** | Launch apps, files, and folders | ✓ |
| 🌐 | **Open website** | Your favorite sites at the push of a button | ✓ |
| 💻 | **Run command** | For power users: any command line | Separate command per direction |
| 📝 | **Type text** | Signatures, email addresses, snippets | ✓ |
| 🗂️ | **Switch profile** · ☀️ **Brightness** | One button, a new layout | Smooth brightness |
| 📑 | **Switch page** | Next, previous, or a specific page | Flip through pages |

And the best part: every key shows on its display what it does – with the real app icon or game cover, plus your own title if you want one.

## ❓ FAQ

<details>
<summary><b>Windows shows a warning during installation – is that normal?</b></summary>

Yes. The installer is not digitally signed (yet), so Windows SmartScreen shows a warning.
Click <i>"More info" → "Run anyway"</i>.
</details>

<details>
<summary><b>My device is not detected.</b></summary>

Close the N3 manufacturer software if it is running – only one program can talk to the device at a time.
On Linux, OpenDeckN3 needs access rights once (the app shows you the right command).
</details>

<details>
<summary><b>Does OpenDeckN3 run on Linux?</b></summary>

Yes, OpenDeckN3 works on Linux – currently from source. Ready-made packages will follow.
See the <a href="docs/ENTWICKLUNG.md">developer docs</a> (German) for how.
</details>

<details>
<summary><b>How do I get updates?</b></summary>

Automatically: OpenDeckN3 checks for a new version at startup and every few hours, and asks you before anything happens.
Clicking <i>"Update now"</i> downloads the update, verifies it, and restarts the app – your profiles are kept.
Under <i>Settings → Updates</i> you can also check manually, turn off pre-releases, or turn on <i>"Update app automatically"</i> –
then updates install without asking.
Plugins from the catalog keep themselves up to date; turn this off there with <i>"Update plugins automatically"</i>.
</details>

<details>
<summary><b>Where are my profiles stored?</b></summary>

On Windows in <code>%APPDATA%\opendeckn3</code>, on Linux in <code>~/.config/opendeckn3</code>.
They are kept even if you uninstall. In the app: <i>Settings → Configuration folder → Open</i>.
</details>

<details>
<summary><b>Does OpenDeckN3 cost anything?</b></summary>

No. OpenDeckN3 is free software under the GPL-3.0 – free of charge, no ads, no subscription.
</details>
